 Система зачисления в ВУЗ
Веб-приложение для автоматизации процесса приёма абитуриентов: выбор специальностей и групп с учётом квот, подача заявления онлайн и администрирование зачисленных студентов через защищённую панель управления.

 Быстрый запуск (Getting Started)
 Системные требования
- PHP: Версия `8.0` или выше
- MySQL/MariaDB: Локальная СУБД (порт 3306 по умолчанию)
- Веб-сервер: Apache (рекомендуется сборка XAMPP)
- Браузер: Современный (Chrome, Firefox, Edge) с поддержкой JS

💻 Установка и запуск
1. Развёртывание:
   Скопируйте папку проекта в корневую директорию веб-сервера:
   `C:\xampp\htdocs\students\`

2. Инициализация базы данных:
   Откройте в браузере: `http://localhost/students/setup.php`
   Скрипт автоматически создаст БД `university_db`, таблицы и тестовые данные.

3. Запуск:
   - Абитуриент: `http://localhost/students/applicant.php`
   - Администратор: `http://localhost/students/login.php` (логин: `admin`, пароль: `admin`)

📦 Архитектура
Приложение построено по классической MVC-подобной схеме с разделением логики:
- `*_actions.php` — обработка POST-запросов и изменение состояния БД
- `*.php` — представление и клиентская логика
- `get_groups.php` — REST-like эндпоинт для динамической подгрузки групп через AJAX
