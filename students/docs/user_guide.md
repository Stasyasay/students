📖 Руководство пользователя (User Guide)
Интерфейс системы разделён на два независимых потока: Абитуриент и Администратор. Вход в каждый поток осуществляется с главной страницы `index.php`.

1️⃣ Режим «Абитуриент»
Назначение: Подача заявления на зачисление с автоматическим контролем свободных мест.
Цветовая индикация: Кнопки и формы подсвечены градиентом (фиолетово-синий), активные элементы анимированы.
Процесс:
1. Выбор специальности из выпадающего списка.
2. Динамическая подгрузка доступных групп с указанием количества мест (capacity - enrolled).
3. Переход к форме заполнения: ФИО, Email, Телефон.
4. Подтверждение зачисления → страница успеха с двумя кнопками:
     Вернуться к заявке
     Посмотреть список зачисленных
Результат: Данные студента фиксируются в БД, квота группы уменьшается на 1.

2️⃣ Режим «Администратор»
Назначение: Управление справочниками и мониторинг зачисленных.
Защита: Сессионная авторизация (логин/пароль: `admin`/`admin`). Выход через кнопку «Выйти».
Вкладки панели:
👥 Студенты — таблица всех зачисленных с поиском по ФИО/Email. Действие: удаление записи.
 Специальности — CRUD справочника. Добавление новой, удаление (каскадно удаляет привязанные группы).
🏫 Группы — управление квотами. Привязка к специальности, указание названия и вместимости.
Доступные действия:
✅ Добавление элементов через inline-формы
🗑 Удаление с подтверждением (confirm)
🔍 Фильтрация студентов в реальном времени
